1.  Проверка порядка задач.
	   T1_RESET  -  Очищает граф зависимостей
	   T1_ADDTASK <буква>  -  Регистрирует задачу (A-Z)
	   T1_DEP <значение 1> <значение 2>  -  Задача A зависит от B
	   T1_CHECK  -  Проверяет наличие цикла (Возможно/Невозможно)
2.  АТД Множество
	   SETADD <значение>  -  Добавляет элемент (выводит TRUE/FALSE)
	   SETDEL <значение>  -  Удаляет элемент (выводит TRUE/FALSE)
	   SET_AT <значение>  -  Проверяет наличие (выводит TRUE/FALSE)
	   SETPRINT  -  Выводит текущее множество
3.  Разбиение множества
	   T3_CLEAR  -  Очищает множество (глобальный `mySet`)
	   T3_ADD <целое_число>  -  Добавляет число в множество
	   T3_PRINT  -  Выводит текущее множество
	   T3_PARTITION <целевая_сумма>  -  Пытается разбить на подмножества
4.  Различные подмассивы
	   T4_CLEAR  -  Очищает массив (глобальный `arr`)
	   T4_ADD <значение>  -  Добавляет элемент в массив
	   T4_SUBSETS  -  Выводит все подмножества (подмассивы)
5.  Высота дерева
	   TINSERT mytree <целое>  -  Добавляет число в дерево (игнорирует дубликаты)
	   THEIGHT mytree  -  Выводит высоту дерева
6. 1. Хеш-таблицы
	   H1_SET <ключ> <знач>  -  Добавляет/обновляет в методе цепочек
	   H1_GET <ключ>  -  Ищет ключ в методе цепочек
	   H1_DEL <ключ>  -  Удаляет ключ из метода цепочек
	   H1_CLEAR  -  Очищает таблицу цепочек
	   H2_SET <ключ> <знач>  -  Добавляет/обновляет в кукушке
	   H2_GET <ключ>  -  Ищет ключ в кукушке
	   H2_DEL <ключ>  -  Удаляет ключ из кукушки
	   H2_CLEAR  -  Очищает таблицу кукушки
    2.Подстрока
	  LONGEST <строка>  -  Ищет самую длинную подстроку без повторов
7.  LRU-кэш
	   LRU_INIT <емкость>  -  Инициализирует кэш (сбрасывает старый)
	   LRU_SET <ключ> <знач>  -  Добавляет/обновляет пару в кэше
	   LRU_GET <ключ>  -  Получает значение (или -1)
	   LRU_PRINT  -  Выводит текущее состояние кэша (от старых к новым)
